Explore o GitHub Copilot em todo o ciclo de desenvolvimento de software usando cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar comportamentos, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é um novo desenvolvedor da Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com tema de desenvolvedor. O backlog da sua equipe já está registrado como issues do GitHub e pronto para você assumir. Ele inclui trabalhos de funcionalidades, como filtragem e paginação, juntamente com melhorias de qualidade, como acessibilidade e padrões de codificação.

## Escolha seu ambiente

O GitHub Copilot acompanha você em todos os lugares em que trabalha. Escolha o ambiente que corresponda à forma como você deseja desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra práticos.

### [Aplicativo GitHub Copilot][app]

Execute sessões de agentes em paralelo, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente seu trabalho, monitore o progresso e revise os pull requests que ele abre.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
