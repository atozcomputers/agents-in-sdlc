通过真实场景、完整应用程序和共享积压工作，探索软件开发生命周期中的 GitHub Copilot。将迭代地规划更改、创建代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，面向以开发者为主题的桌游提供众筹服务。团队的积压工作已整理为 GitHub议题，随时可以领取，其中包括筛选和分页等功能工作，以及无障碍和编码规范等质量改进。

## 选择工作环境

GitHub Copilot 可在多种工作环境中提供帮助。选择与你期望的构建方式相匹配的环境。每个研讨会都有独立的设置，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。使用计划与自动驾驶模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot app][app]

运行并行智能体会话、切换会话模式、协作使用 Canvas，并在桌面应用中管理 GitHub议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub议题分配给异步智能体，指导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。使用 Copilot Chat 智能体模式、MCP服务器和自定义智能体，无需离开编辑器。
